# Telegram Mini App — криптообменник (черно-золотой)

Прототип-витрина для клиента. Без сборки и без своего сервера: чистые HTML/CSS/JS.

## Решения
- Бренд временный — `Aurum Exchange` (бот со скрина клиента чужой, его бренд не копируем). Меняется в `js/config.js`.
- Курсы живые: крипта — CoinGecko, фиат — open.er-api.com; поверх — наценка `marginPercent`. Если API недоступны — `fallback` из конфига.
- Заявка: открывается чат оператора (`t.me/<operator>?text=…`) + текст копируется в буфер. Бэкенда нет.
- Языки: en, ru, kk, uk, tr, ar (RTL), es, de. Язык по умолчанию — из Telegram пользователя.
- Пары фиат↔фиат запрещены (вторая сторона становится USDT).
- Текст заявки для оператора — на языке `orderLang` (en).

## Что где
- `js/config.js` — бренд, оператор, наценка, минимум, валюты, способы оплаты, банки
- `js/i18n.js` — все тексты интерфейса
- `js/rates.js` — загрузка курсов и пересчёт
- `js/app.js` — логика, рендер, заявка, Telegram WebApp API
- `css/style.css` — тема (токены в `:root`)
- `README.md` — как запустить локально и подключить к боту
- Локальный просмотр: `.claude/launch.json` → `python -m http.server 5173`
